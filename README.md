# 🎵 Music Player


A modern and responsive **Music Player** built with **HTML, CSS, and JavaScript** featuring a clean glassmorphism UI, animated background blur, album artwork, and intuitive playback controls. The player delivers a smooth music listening experience with an elegant interface. ([GitHub][1])

---

## ✨ Features

* 🎶 Play / Pause music
* ⏮ Previous & ⏭ Next controls
* 📀 Beautiful album artwork
* 🎨 Glassmorphism music card
* 🌈 Dynamic blurred background
* 📱 Responsive design
* 🎧 Smooth audio progress bar
* ❤️ Minimal and elegant UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
